# CLAUDE.md

## Project

Storefront — React + TypeScript web app.

## Commands

- `yarn install` — install dependencies
- `yarn dev` — start dev server
- `yarn test` — run unit tests (Jest)
- `yarn lint` — lint
- `yarn build` — build

## Testing

- Use Jest for unit tests. Snapshot-test components.
- ESLint uses the Airbnb config.

## General

- Write clean code.
- Use meaningful names.
- Keep functions small.

## Planning

- If a change is over 50 lines, write a plan first.
